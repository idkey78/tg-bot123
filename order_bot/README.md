# Telegram-бот для приймання замовлень

Бот на **aiogram 3** + **SQLite (aiosqlite)**. Клієнти оформлюють замовлення на навчальні практичні, власник керує всім через Telegram (`/admin`). Оплата — лише особисто, платіжних систем у боті немає.

## Можливості
- Предмети: «Обробка інформації», «Комп'ютерна інженерія». Практичні додає адміністратор.
- **Custom-практична**: клієнт надсилає файл(и) із завданням (документи, фото, відео, аудіо, до 10) та текстовий опис.
- Оплата: звичайна (ціна адміністратора) або Custom-пропозиція (текст/сума).
- Під час замовлення бот питає **ім'я, прізвище та групу** — є кнопка «Пропустити».
- Підсумок із кнопками «Відправити / Редагувати / Скасувати», захист від подвійного натискання.
- Ліміт: 3 замовлення за ковзні 24 години (за Telegram ID, зберігається після перезапуску).
- **Коментарі до замовлення**: клієнт і адміністратор обмінюються повідомленнями; кожна сторона отримує сповіщення з кнопкою «Відповісти».
- **Видача виконаної роботи**: адмін у деталях замовлення натискає «📤 Надіслати виконану роботу», кидає файли в бот — вони одразу доставляються клієнту. Кнопка «Готово» позначає замовлення виконаним. Клієнт може повторно отримати файли в «Мої замовлення».
- Адмін-панель: практичні (додати/редагувати/ціна/вкл-викл/видалити), замовлення зі статусами, статистика, налаштування (пауза прийому, текст «Допомога»).

## Запуск
1. **Python 3.12+** — з https://www.python.org/downloads/ (на Windows поставте галочку «Add Python to PATH»).
2. **Створіть бота**: у Telegram відкрийте `@BotFather` → `/newbot` → вкажіть назву та username (закінчується на `bot`).
3. **BOT_TOKEN** — BotFather надішле токен вигляду `123456789:AAA...`. Нікому його не показуйте.
4. **Ваш Telegram ID** — напишіть `@userinfobot`, він надішле число (Id).
5. **.env**: скопіюйте `.env.example` у `.env` і заповніть `BOT_TOKEN` та `ADMIN_ID`.
6. **Залежності**:
   ```
   python -m venv .venv
   .venv\Scripts\activate        (Windows)   |   source .venv/bin/activate   (Linux/macOS)
   pip install -r requirements.txt
   ```
7. **Запуск**: `python -m bot.main` (з папки проєкту).
8. **Перевірка**: напишіть боту `/start` — з'явиться меню; з вашого акаунта `/admin` — адмін-панель. Додайте практичну, оформіть тестове замовлення з іншого акаунта, змініть статус, надішліть файл «виконаної роботи».
9. **Резервна копія**: `python -m bot.utils.backup` — створить `backups/bot_ДАТА.db` (можна при працюючому боті). Також можна просто скопіювати `data/bot.db` при зупиненому боті.

## Структура
```
bot/main.py            точка входу, збірка Dispatcher
bot/config.py          .env
bot/constants.py       предмети, статуси, ліміти
bot/database/          database.py (SQLite), models.py, requests.py (усі запити)
bot/handlers/user/     start, subjects, orders (оформлення), my_orders, comments
bot/handlers/admin/    panel, practicals, orders, delivery, comments, statistics, settings
bot/keyboards/ states/ filters/ middlewares/ services/ utils/
tests/
```

## Важливо знати
- Стани діалогів (FSM) зберігаються в пам'яті: після перезапуску незавершене оформлення скинеться (старі кнопки покажуть «неактуальна»). Дані в базі — зберігаються.
- Запускайте лише **один** екземпляр бота з одним токеном.
- Адміністратор має хоча б раз натиснути `/start` у боті, щоб отримувати сповіщення.
- Якщо клієнт заблокував бота, сповіщення/файли йому не доставляться — бот про це попередить.
